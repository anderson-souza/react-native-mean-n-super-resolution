# react-native-mean-n-super-resolution

Uma lib para fazer super resolution de um conjunto de imagens utilizando OpenCV

## Installation


```sh
npm install react-native-mean-n-super-resolution
```


## Usage


```js
import { multiply } from 'react-native-mean-n-super-resolution';

// ...

const result = multiply(3, 7);
```
